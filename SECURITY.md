# 🔒 Security Policy

KinotiX takes security and user privacy extremely seriously. We appreciate the responsible disclosure of any security vulnerabilities found in our codebase or mobile client.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report security vulnerabilities directly to our security team via email at **kinotix.app@gmail.com**.

### What to Include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept script to reproduce the issue.
- Affected Android versions or app build numbers.

### Response SLA:
- We will acknowledge receipt of your vulnerability report within **24 hours**.
- We aim to issue a fix release or security update within **7 business days**.
